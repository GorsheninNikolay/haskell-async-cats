## haskell-async-cats

### О чём задача

Нужно написать программу на Haskell, которая:

- **скачивает** котиков по HTTP `GET /cat` (jpeg),
- **дедуплицирует** их (ищет уникальные),
- **сохраняет результат** обратно в сервис через `POST /cat`.

В текущей реализации сделан **простой вариант**: мы собираем **12 уникальных** котиков, кладём их в **ZIP-архив** и отправляем архив в сервис через **`multipart/form-data`** с полем **`file`** (аналогично `curl -F "file=@cats.zip" ...`).

## Эндпойнты для теста

- **Без задержки (для отладки)**: `http://algisothal.ru:8890/cat`
- **Со случайной задержкой (до ~15с)**: `http://algisothal.ru:8889/cat`

URL сейчас задаётся в `app/Main.hs` (см. `mkCatService`).

### Как устроено в коде

- **`app/Cat/Types.hs`**: доменные типы.
  - `CatImage` = байты jpeg (`catBytes`) + хэш (`catHash`) для дедупликации.
- **`app/Cat/Api.hs`**: HTTP-клиент.
  - `fetchCatImage` — GET `/cat` и сразу возвращает `CatImage` (байты + хэш).
  - `postCatFileMultipart` — POST `/cat` как `multipart/form-data` с полем `file` (используется для загрузки ZIP).
- **`app/Cat/Factory.hs`**: “фабрика” асинхронных задач.
  - держит ограниченное число in-flight задач,
  - по завершению каждой задачи решает: **unique / duplicate / error**,
  - останавливается и отменяет остаток задач, когда собрано **12/12**.
- **`app/Cat/Zip.hs`**: упаковка котиков в ZIP в памяти.
  - файлы внутри архива: `cat-01.jpg` .. `cat-12.jpg`.
- **`app/Main.hs`**: входная функия main.
  - собрать 12 уникальных → `catsToZip` → `postCatFileMultipart`.
  - перед запуском очищает `static/cats`, затем сохраняет туда `cat-01.jpg..cat-12.jpg` и `cats.zip`.

### Как запустить

Требуется установленный GHC + Cabal (обычно через `ghcup`).

Сборка и запуск:

```bash
cabal run
```

Ожидаемое поведение:

- в консоль пишутся логи фабрики (старт/успех/дубликаты/ошибки),
- когда собрано **12/12**, ZIP загружается в сервис через `POST /cat`.
- локальные файлы текущего запуска лежат в `static/cats`.
